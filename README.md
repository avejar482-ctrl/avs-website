# AVS website concept

Static, responsive AVS landing page. The site is a design concept, not a working storefront.

## Deploy on Vercel
1. Create a GitHub repository (e.g. `avs-website`).
2. Upload `index.html` to the repository root (not inside another folder).
3. In Vercel, choose Add New > Project, import the GitHub repository.
4. Framework Preset: Other. Root Directory: `./`. Click Deploy.

## Before launch
- Replace `hello@example.com` in `index.html` with a working email or replace the link with a real signup form.
- Connect a commerce backend for payments, inventory, checkout and subscriptions.
- Confirm formulations, labeling, claims, availability and regulatory compliance before offering pouches for sale.
- Replace the CSS concept can with approved product photography when available.
- Add privacy policy, terms, contact details, shipping and returns information.
